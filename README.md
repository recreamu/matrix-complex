# matrix-complex

Программный комплекс консольных приложений — практическая работа №2
по дисциплине «Коллективная разработка и управление программными проектами»
(вариант 6).

## Состав комплекса

| Файл | Назначение |
|---|---|
| `calculator.py` | Калькулятор: вычисление выражения вида `a оператор b` |
| `matrix_max.py` | Поиск максимального элемента матрицы NxM и его индексов |
| `matrix_add.py` | Сложение двух матриц |
| `matrix_sums.py` | Суммы элементов каждой строки и каждого столбца матрицы |

## Подмодуль

Общий для всех приложений код ввода-вывода и операций над матрицами вынесен
в отдельный репозиторий и подключён как подмодуль Git в каталог `libs/matrixlib`.

Клонирование комплекса вместе с подмодулем:

```bash
git clone --recursive https://github.com/recreamu/matrix-complex.git
```

Если репозиторий уже склонирован без ключа `--recursive`:

```bash
git submodule init
git submodule update
```
